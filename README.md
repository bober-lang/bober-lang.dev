# bober-lang.dev

The website of the Bober programming language: `install.sh`, served as https://bober-lang.dev/install.sh, and the docs at
https://docs.bober-lang.dev, plain HTML that cmark-gfm makes of `pages/` and what `bober skill` and `bober doc` print.

Build locally with `bober` and `cmark-gfm` on `PATH`: `./build.sh` writes the site to `site/`.
